# 🌐 Web Responsivo

Projeto desenvolvido com foco em **responsividade**, criando páginas que se adaptam a diferentes tamanhos de tela 📱💻.

Este repositório faz parte da minha jornada de aprendizado em desenvolvimento web, onde estou praticando HTML, CSS e conceitos modernos de design responsivo.

## 🚀 Sobre o projeto

O objetivo deste projeto é criar interfaces bonitas, organizadas e adaptáveis para diferentes dispositivos, proporcionando uma melhor experiência para o usuário.

Ainda estou desenvolvendo e melhorando o projeto constantemente, então novas atualizações podem acontecer a qualquer momento ✨

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Responsividade
* Flexbox
* Media Queries

O design responsivo permite que um site se adapte automaticamente a diferentes tamanhos de tela, como celulares, tablets e computadores.

## 📱 O que estou praticando

* Estruturação de páginas web
* Criação de layouts responsivos
* Organização visual
* Boas práticas de CSS
* Adaptação para dispositivos móveis

## 🎯 Objetivos

* Melhorar minhas habilidades em Front-end
